# Woordenlijst: stijfwoord naar gewoon woord

Substitutielijst bij Formulering 1. De lijst is voor deze repo samengesteld uit gangbaar
Nederlands taaladvies; raadpleeg Taaltelefoon voor het officiële advies per woord. De
lijst is richtinggevend, geen gesloten lijst: bestaat er een gewoner woord met dezelfde
betekenis en gevoelswaarde, gebruik dat.

## Uitbreiding: naamwoordstijl

Een handeling hoort in een werkwoord, niet in een zelfstandig naamwoord.

| Liever niet | Maar wel |
|---|---|
| het indienen van de aanvraag | dien de aanvraag in |
| voor het aanvragen van de subsidie | om de subsidie aan te vragen |
| bij het opstarten van de dienst | als de dienst opstart |
| de uitvoering van de migratie | we voeren de migratie uit |
| overgaan tot verwijdering van | verwijderen |
| een verhoging van de limiet doorvoeren | de limiet verhogen |

## Uitbreiding: vage woorden

Vervang door een getal, een datum of een naam. Lukt dat niet, schrap het woord.

| Vaag | Vraag jezelf af |
|---|---|
| binnenkort, op korte termijn | welke datum? |
| diverse, een aantal | hoeveel? |
| de nodige maatregelen | welke maatregelen? |
| performant, robuust, krachtig | welk cijfer bewijst dat? |
| in principe, eigenlijk, min of meer | geldt het of niet? |
| er wordt gewerkt aan | wie werkt eraan? |

## Eén woord per begrip

Kies per document één term en houd die vol. De linter meldt de rotatie van deze groepen.

| Begrip | Kies één van |
|---|---|
| nakijken | controleren / nakijken / verifiëren / checken |
| instellingen | instellingen / configuratie / settings |
| uitvoeren | uitvoeren / runnen / draaien |
| verwijderen | verwijderen / wissen / deleten |
| aanmaken | aanmaken / creëren / opzetten |
| fout | fout / error / storing |

## Vakjargon in IT-teksten

Vervang jargon niet blind. *Pipeline*, *commit*, *pull request*, *container* en *cluster*
zijn de dagelijkse woorden van de doelgroep; een gedwongen vertaling maakt de tekst
juist onduidelijker. Leg de term uit als de doelgroep hem niet kent, en schrijf hem
consequent op dezelfde manier.
